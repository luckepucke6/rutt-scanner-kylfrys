Jag har en webbapp (index.html) på GitHub Pages som heter Rutt-scanner. Jag vill integrera Supabase så att ruttdata och loggning delas mellan alla enheter.
Gör följande:

1. Skapa en .env fil med variablerna SUPABASE_URL och SUPABASE_ANON_KEY (lämna dem tomma, jag fyller i värdena själv)
2. Skapa eller uppdatera .gitignore så att .env inte pushas till GitHub
3. Uppdatera index.html så att den:

- Laddar Supabase JS-biblioteket via CDN
- Läser URL och anon key från en konfigurationsvariabel längst upp i filen (som jag enkelt kan byta ut mot mina riktiga värden)
- Sparar alla inlästa ruttdata till Supabase-tabellen route_entries (kolumner: kof, route, store_name, driver)
- Hämtar ruttdata från Supabase vid start så att alla enheter ser samma data
- Loggar varje sökning till tabellen search_logs (kolumner: kof, route_found, success, device_id, searched_at)
- Genererar ett unikt device_id per telefon och sparar det i localStorage


4. Behåll all befintlig funktionalitet — kamera-scanning, S-rutt-logik, förarnamn, ruttöversikt
